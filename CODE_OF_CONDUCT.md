# Code of Conduct

## Expected Behavior

Contributors are expected to:

- discuss technical tradeoffs directly and respectfully
- keep feedback concrete and evidence-based
- challenge ideas without attacking people
- prefer clarity over posturing
- keep changes scoped and traceable

## Unacceptable Behavior

Avoid:

- personal attacks
- dismissive or hostile review behavior
- intentionally misleading technical claims
- spam, harassment, or bad-faith participation

## Repository Culture

This repository values:

- rigor
- practicality
- recoverability
- clear process
- evidence before claims

## Reporting

If behavior becomes disruptive, contact the repository owner privately first when practical.
