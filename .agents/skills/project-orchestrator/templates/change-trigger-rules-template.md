# Change Trigger Rules

## Escalate Immediately If Change Affects
- [ ] Project goal
- [ ] Technology stack
- [ ] Milestone acceptance
- [ ] Core data model
- [ ] Permissions/security boundary
- [ ] Core UI structure
- [ ] Key external integration
- [ ] Validity of active plan

## Default Non-Escalation Cases
- Low-risk polish
- Local implementation detail
- Internal naming cleanup
- Non-critical refactor within approved scope
