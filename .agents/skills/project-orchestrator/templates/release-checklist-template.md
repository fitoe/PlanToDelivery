# Release Checklist

## Release Scope
- Milestone or project:
- Date:

## Pre-Release
- [ ] Acceptance criteria reviewed
- [ ] Fresh verification complete
- [ ] Required regressions complete
- [ ] Environment config verified
- [ ] Migration strategy verified if needed
- [ ] Rollback path clear

## Release
- [ ] Deployment executed
- [ ] Health checks pass
- [ ] Critical user flow smoke checks pass

## Post-Release
- [ ] Monitoring reviewed
- [ ] Alert status reviewed
- [ ] Known issues recorded
- [ ] Handoff updated
